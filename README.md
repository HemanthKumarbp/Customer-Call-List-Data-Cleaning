# Customer Call List Data Cleaning

## Overview
This project focuses on cleaning a Customer Call List dataset using Python. The goal is to improve data quality by handling missing values, removing duplicates, fixing inconsistent formats, and preparing the data for further analysis.

## Dataset
The dataset contains customer call records with fields such as customer name, phone number, call date, call duration, and call outcome.

## Data Cleaning Steps
- Handling missing values  
- Removing duplicate records  
- Standardizing phone number formats  
- Correcting inconsistent date formats  
- Fixing invalid or erroneous entries  

## Tools & Libraries
- Python  
- Pandas  
- NumPy
